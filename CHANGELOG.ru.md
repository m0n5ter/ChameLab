# Журнал изменений
Русская версия [CHANGELOG.md](CHANGELOG.md): те же разделы и пункты в том же порядке. Каждый пункт пишется сразу на обоих языках.
Анонс релиза в Telegram берётся из этого файла, в Discord — из английского.

Релизы помечаются версией ChameLab, которая растёт с каждым релизом (с v1.0.7).
У прошивки своя версия в `firmware/VERSION` (с v2.3.2-cl); она меняется, только когда меняется прошивка.

Каждый релиз (с v1.4.35) начинается с `### Кратко`, до трёх самых важных изменений, за ним идёт `### Подробно`, полный список. Анонсы релиза в Telegram и Discord и страница загрузок показывают краткую часть со ссылкой на этот файл.

## [v1.5.40][2026-11-11] · прошивка v2.3.15-cl
### Кратко
 - ChameLab: «Поделиться устройством» даёт пользоваться вашим хамелеоном с другого компьютера через интернет: подключаются по коду вида RU1-ABCD-1234
 - ChameLab: подбор ключей стал быстрее: Darkside до 20 раз, static encrypted nested примерно в 3 раза, nested примерно в 1,4 раза
 - ChameLab: static encrypted nested читает карты со стандартными ключами без криптоанализа и больше не ведёт долгий бесполезный перебор на обычных картах с backdoor

### Подробно
 - ChameLab: «Поделиться устройством» на странице подключения (настольное приложение) открывает доступ к выбранному хамелеону через самый быстрый из пяти relay-серверов (Турция, Болгария, Германия, Россия, США) и показывает код вида RU1-ABCD-1234. «Подключиться к общему устройству» с этим кодом на другом компьютере или Android-телефоне работает с хамелеоном так, будто он подключён напрямую. Пока доступ открыт, страница подключения показывает только этот хамелеон, код, кто подключён (пользователь@компьютер) и трафик в обе стороны. Одновременно подключается один человек; он может выйти и снова подключиться по тому же коду, а «Закрыть доступ» завершает доступ. Соединения с relay-серверами шифруются, сертификат каждого сервера встроен в приложение; браузерная версия к общим устройствам подключаться не может
 - ChameLab: Static encrypted nested сначала проверяет известные и заводские ключи, поэтому карты со стандартными ключами читаются без криптоанализа; перед расчётом кандидатов повторный сбор проверяет неизменность зашифрованных nonce и предотвращает долгий бесполезный перебор на обычных картах с backdoor
 - ChameLab: восстановление nested, static encrypted nested и Darkside использует общие начальные кандидаты Crypto1, считает независимые группы параллельно и проверяет префиксы Darkside пачками: на компьютере Darkside быстрее в 7–21 раз, static encrypted nested — в 3–3,7 раза, nested — в 1,4–1,5 раза
 - ChameLab: у кнопок «Подключить» новая иконка, большая кнопка «Подключить» больше не растягивается на всю карточку, а однострочные поля ввода держат текст по центру по вертикали
 - ChameLab: в сниффинге HF кнопки «Загрузить» и «Сохранить» больше не меняют надпись «Захват» на «Слушаю»; надпись меняется только во время захвата
 - ChameLab: сниффинг HF показывает время каждого кадра от начала захвата и паузу после предыдущего кадра. Прошивка v2.3.15-cl записывает границы кадров аппаратным таймером; время сохраняется при загрузке и сохранении файлов Proxmark3 `.trace`, старые прошивки продолжают работать без измеренных меток времени

## [v1.4.39][2026-11-10] · прошивка v2.3.14-cl
### Кратко
 - ChameLab: подбор ключей MIFARE Classic по словарю стал намного быстрее: прошивка проверяет ключи пачками, а не по одной аутентификации на ключ, — сильнее всего на телефоне по Bluetooth
 - ChameLab: у «Подобрать ключи» появились настройки перебора: способ перебора, начальный сектор и порядок секторов
 - ChameLab: подбор пароля T55XX по словарю больше не обрывается раньше времени, когда чтение не находит метку

### Подробно
 - ChameLab: подбор ключей MIFARE Classic по словарю проверяет словарь пачками, по одной команде прошивки на пачку (8 ключей по USB, 32 по Bluetooth), вместо отдельной аутентификации на каждый ключ — заметно быстрее, сильнее всего на телефоне по Bluetooth; когда пачка открывает сектор ключом A, прошивка читает ключ B прямо из трейлера сектора. Словарь проверяется один раз: после прохода пачками посекторный поиск пробует только ключи, открывшие другие сектора. Найденные ключи и прогресс видны, пока идёт пачка, а при сбое пачки подбор переходит на проверку по одному ключу. Прошивка без этой команды по-прежнему проверяет ключи по одному
 - ChameLab: кнопка настроек рядом с «Подобрать ключи» открывает «Настройки перебора», которые запоминаются между запусками: «Способ перебора» («По одному ключу», «Пачками по всем секторам», «Пачками в одном секторе»), «Начальный сектор» («Первый сектор» или «Выделенный сектор») и «Порядок секторов» («По порядку» или «В случайном порядке»)
 - ChameLab: подбор пароля T55XX по словарю больше не прерывается на неверном ключе, когда чтение не находит метку: чтение исходного ID уже доказывает, что запись не прошла, а проверка целостности метки делает до трёх попыток чтения
 - ChameLab: в настройках пароля T55XX подсказка для «Оставить» выровнена так же, как для «Очистить»

## [v1.4.35][2026-11-05] · прошивка v2.3.12-cl
### Кратко
 - CLI: клиент командной строки переписан на C# на том же коде протокола и восстановления ключей, что и приложение; он поставляется одной самодостаточной программой для Windows, macOS и Linux, Python ставить не нужно
 - ChameLab: новый логотип в приложении и на сайте
 - ChameLab для Android: подключение по USB работает (раньше устройство перезагружалось через секунду после подключения)

### Подробно
 - CLI: клиент командной строки переписан на C#: протокол, модели карт и восстановление ключей (darkside, nested, static nested, hardnested, Ultralight C) у него общие с приложением вместо Python-клиента и его нативных решателей. Все команды, флаги и форматы файлов Python-клиента сохранены, есть история и автодополнение по Tab, повторяемый `-c` / `--command`, остановка команды по Ctrl+C и осмысленные коды выхода. В релизе он лежит как `client-windows.zip`, `client-linux.zip` и `client-macos.zip` — самодостаточная программа `chamelab`, которой не нужны ни Python, ни .NET
 - CLI: инструменты разработки тоже на C# (импорт таблиц и генерация кода hardnested, бенчмарки, чтение MIFARE Classic 4K, упаковка и анонсы релизов); вспомогательные скрипты DFU переехали в `firmware/tools`
 - Сайт: на главной сказано, что CLI написан на C# и использует код приложения
 - Сайт: страница загрузок показывает краткое описание релиза со ссылкой на полный журнал изменений; анонсы в Telegram и Discord тоже
 - ChameLab: новый логотип, геометрически перерисованный хамелеон с шестерёнкой: иконка приложения, заставка на Android, иконка окна и .exe в Windows и знак в верхней панели (вместо картинки ChameleonUltra)
 - Сайт: в шапке новый логотип вместо значка «C» и без точки после ChameLab; у сайта и веб-приложения (app/ и dev/) новый favicon (у веб-приложения был стандартный значок браузера)
 - Сайт: в заголовке главной страницы нет точки, а «Лаборатория для вашего» набрана мельче над «Chameleon»
 - Сайт: в шапке главной страницы вместо большой фотографии ChameleonUltra логотип ChameLab
 - Сайт: заголовки больше не заканчиваются точкой
 - Сайт: на странице загрузок кнопка веб-приложения стоит первой на всю ширину, а пакеты прошивки идут по два в ряд: ChameleonUltra сверху, ChameleonLite снизу, а два бинарника прошивки для SWD делят весь ряд пополам; на узком экране они идут по одному в ряд. Клиент командной строки стоит перед прошивкой
