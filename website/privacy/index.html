PRIVACY

Privacy policy

Last updated: November 13, 2026. This policy covers the ChameLab app on every platform (Windows, macOS, Linux, Android, iOS and the web app) and this website.

In short

ChameLab has no accounts, no ads, no analytics and no tracking in the app. Everything you read, save or edit stays on your device and on your ChameleonUltra or ChameleonLite. The only exception is device sharing, which you start yourself: then the data exchanged with the device passes through a ChameLab relay server, which forwards it and keeps none of it.

Data on your device

  • Saved cards, dumps, key dictionaries, sniffed traces and settings are stored only in the app's own storage on your device, or in the browser's storage for the web app.
  • Files leave the app only when you export or share them yourself.
  • Uninstalling the app, or clearing the site's data in the browser, deletes them.

Network requests

The app connects to the internet only to:

  • check GitHub (api.github.com) for a newer app or firmware release, and download a firmware update from GitHub when you install one;
  • open links you tap, such as the release page or the guide, in your browser;
  • share a device or join a shared one, described below.

These requests carry no personal data. GitHub sees your IP address, as with any web request, under the GitHub privacy statement. The app copy installed from Google Play does not check GitHub for app updates: Google Play updates it.

Device sharing

Sharing lets someone else use your Chameleon remotely with a one-time code. It runs only while you share or join, and never in the background.

  • The app measures the response time of the ChameLab relay servers (in Turkey, Bulgaria, Germany, Russia and the USA) and uses the fastest one.
  • The relay forwards the bytes between the device and the person who joined, over an encrypted (TLS) connection. It does not store them, does not look into them and does not log them.
  • The relay sees the IP addresses of both sides. It uses them only in memory, to limit how often codes can be tried, and does not keep them. Its log holds only when a share opened and closed and how long it lasted.
  • The person you give the code to can send any command to your device while connected, including reading and changing its slots. Share codes only with people you trust, and stop sharing when done.

Permissions

  • Bluetooth (nearby devices): to find and connect to your Chameleon. The app does not use Bluetooth scanning to work out your location. On Android 11 and older the system calls this permission location; the app never reads your location.
  • USB: to talk to a Chameleon plugged in by cable.
  • Vibration: an optional buzz when a scan finishes.
  • Internet: for the update checks and device sharing above.

This website

The website uses Cloudflare Web Analytics, which counts page visits without cookies and without identifying visitors. The web app itself sends nothing anywhere except the GitHub requests and device sharing above.

Children

ChameLab is a tool for working with RFID hardware and is not aimed at children. It collects no personal data from anyone.

Changes and contact

Changes to this policy are published on this page and in the source repository. Questions go to GitHub issues.
