PRIVACY

Privacy policy

Last updated: November 10, 2026. This policy covers the ChameLab app on every platform (Windows, macOS, Linux, Android, iOS and the web app) and this website.

In short

ChameLab has no accounts, no ads, no analytics and no tracking in the app. Everything you read, save or edit stays on your device and on your ChameleonUltra or ChameleonLite. Nothing is sent to the developer.

Data on your device

  • Saved cards, dumps, key dictionaries, sniffed traces and settings are stored only in the app's own storage on your device, or in the browser's storage for the web app.
  • Files leave the app only when you export or share them yourself.
  • Uninstalling the app, or clearing the site's data in the browser, deletes them.

Network requests

The app connects to the internet only to:

  • check GitHub (api.github.com) for a newer app or firmware release, and download a firmware update from GitHub when you install one;
  • open links you tap, such as the release page or the guide, in your browser.

These requests carry no personal data. GitHub sees your IP address, as with any web request, under the GitHub privacy statement. The app copy installed from Google Play does not check GitHub for app updates: Google Play updates it.

Permissions

  • Bluetooth (nearby devices): to find and connect to your Chameleon. The app does not use Bluetooth scanning to work out your location. On Android 11 and older the system calls this permission location; the app never reads your location.
  • USB: to talk to a Chameleon plugged in by cable.
  • Vibration: an optional buzz when a scan finishes.
  • Internet: for the update checks above.

This website

The website uses Cloudflare Web Analytics, which counts page visits without cookies and without identifying visitors. The web app itself sends nothing anywhere except the GitHub requests above.

Children

ChameLab is a tool for working with RFID hardware and is not aimed at children. It collects no data from anyone.

Changes and contact

Changes to this policy are published on this page and in the source repository. Questions go to GitHub issues.
