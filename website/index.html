ChameLab

Desktop, mobile and web app for ChameleonUltra and ChameleonLite, with their firmware and command line client.

Try it in the browser

ChameLab running as WebAssembly, built from the latest main commit. It talks to the device over USB through Web Serial.

Open ChameLab in the browser

Needs Chrome or Edge on a desktop: Firefox and Safari do not support Web Serial.
